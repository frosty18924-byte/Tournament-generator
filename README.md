# Carpet Bowls Pro

An optimized tournament manager for Carpet Bowls, featuring conflict-aware seeding and full finals path generation.

## Features
- **Saturation Engine**: Optimized scheduling to maximize carpet utilization.
- **Conflict-Aware**: Prevents back-to-back matches for teams and variety in carpet assignment.
- **Scalable**: Supports large tournaments (tested up to 40 teams) with automatic group calculation.
- **Vercel Ready**: Deployable as a static web application.

## Deployment
This project is deployed on Vercel: [https://bowls-master.vercel.app](https://bowls-master.vercel.app)

## Local Usage
Simply open `index.html` in any modern web browser.
